The Lorenz System

The curve below traces a solution to the Lorenz system:

\[ \frac{dx}{dt} = \sigma(y - x), \qquad \frac{dy}{dt} = x(\rho - z) - y, \qquad \frac{dz}{dt} = xy - \beta z \]

Set the parameters and initial condition, then press start to trace the solution. Drag to rotate; scroll to zoom. Press stop at any time to explore the curve, then start again to continue. Reset clears the curve and unlocks the sliders.
